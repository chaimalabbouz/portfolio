# Portfolio — Chaima Labbouz

React + Vite. Plain CSS, no UI framework.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

## Edit

- Personal info, links, stack, menu sections: `src/data/profile.js`
- Colors and fonts: `src/styles/theme.css` (`:root` tokens)
- Profile photo: put it in `public/photo.jpg` (initials are shown if missing)

## Deploy (GitHub Pages)

Set `base: '/your-repo-name/'` in `vite.config.js`, then deploy `dist/`.
